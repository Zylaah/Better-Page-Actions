# URLBar Modifier

Enhanced unified extensions panel, highly Arc Inspired.

<img width="277" height="371" alt="image" src="https://github.com/user-attachments/assets/5e3958cc-cfee-4066-bc02-00e996362168" />


## Features

- **Arc Styled Extension Panel and Copy URL Button**

- **Security Information**: Real-time security status display (Secure, Insecure, Mixed Content, Local)
- **Picture-in-Picture Toggle**: Global Auto PiP toggle with visual feedback
- **Action Buttons**: Share URL, Screenshot, Copy URL, and Customize Toolbar buttons
- **Smart Button Positioning**: Unified extensions button moved to optimal location
- **Workspace Color Integration**: Automatically adapts to Zen workspace color changes
- **Extras Menu**: Context menu with cache clearing, cookie management, and permissions

Install via Sine
